## biz-advisor 一句话说明

不写会议纪要（Octic 已有总结），只做宝总做不了的事——**替他看这盘棋**。

流程：读现状 → 钉主体 → 出分析 → 更新人档+线文件 → 六条自检 → 等确认才推飞书。
